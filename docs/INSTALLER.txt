CapsFlow 간편 설치

1. ZIP 압축을 완전히 풉니다.
2. CapsFlow-Installer 폴더 안의 Install.command를 더블클릭합니다.
3. 안내 창의 빌드/복사/등록 결과를 확인합니다. 이 설치 ZIP은 빌드 도구가 필요 없습니다.
4. macOS가 입력 소스 추가를 요구하면:
   시스템 설정 → 키보드 → 텍스트 입력 편집 → ＋ → 한국어 → CapsFlow 한국어 우선 → 추가
   목록에 없으면 작업을 저장한 뒤 로그아웃·로그인하고 추가하세요.
   그다음 같은 Install.command를 다시 실행합니다.
5. CapsFlow가 실행되면 손쉬운 사용(접근성)·입력 모니터링 권한을 직접 허용합니다.
6. 메뉴의 ‘자동’을 선택하고 dkssud + Space → 안녕, hello + Space → hello를 확인하세요.

이미 설치했다면
- 지금 자동 입력기를 사용 중이고 교체가 필요하면 설치기가 멈춥니다.
  입력 내용을 저장하고 ABC 또는 두벌식으로 전환한 뒤 다시 실행하세요.
- 실제로 입력기를 교체할 때는 다른 앱의 조합 중인 글자까지 확정·저장했는지 한 번 확인합니다.
  확인 후 y 또는 예를 입력하세요. 확인을 취소하면 앱을 종료하거나 교체하지 않습니다.
- 같은 파일은 덮어쓰지 않습니다. 설정·입력 기록·사전·권한 DB는 수정하지 않습니다.
- 교체한 기존 앱은 ~/Library/Application Support/CapsFlow/Install Backups/ 아래에 보관합니다.
- 설치 도중 macOS 입력 소스 추가가 필요하면 기존 메뉴 앱은 교체하지 않고 대기합니다.
- 재빌드한 앱을 교체하면 기존 권한이 켜져 있어도 다시 허용해야 할 수 있습니다.

알아두세요
- 사용자 Applications와 Library에만 설치하며 sudo는 사용하지 않습니다.
- 시스템의 ABC·두벌식을 삭제하거나 현재 입력 소스를 강제로 바꾸지 않습니다.
- macOS 권한 승인·입력 소스 추가·로그아웃은 자동으로 강제하지 않습니다.
- 이 패키지는 로컬 ad-hoc 서명이며 Developer ID 서명/Apple 공증이 아닙니다.
  macOS가 차단하면 배포 출처를 확인하고 시스템 안내를 따르세요. 보안 기능을 끄는 방식은 사용하지 마세요.
- ZIP 파일명의 arm64는 Apple Silicon용입니다. 다른 CPU·모든 macOS 버전에 대한 호환성 보장이 아닙니다.
- 검증 환경: Apple Silicon / macOS 27.0.1. 앱의 선언상 최소 대상은 macOS 13입니다.
- 설치 상태만 확인하려면 터미널에서 zsh scripts/setup.sh --check를 실행하세요.
- 앱·설정창을 자동으로 열지 않으려면 zsh scripts/setup.sh --no-open을 실행하세요.

자동 업데이트 (0.3.3부터)
- 메뉴 앱 실행 중 6시간마다 GitHub의 서명된 버전 정보를 확인하고 새 버전을 자동 다운로드합니다.
- 위치: https://raw.githubusercontent.com/kcc920926-droid/capsflow/main/updates/latest-arm64.json
- 메뉴의 업데이트 설정에서 자동 확인·다운로드를 끌 수 있습니다. 입력 내용은 전송하지 않습니다.
- 새 버전은 메뉴바의 ↑로 표시하며, 설치는 입력 저장·ABC/두벌식 전환 후 직접 확인해야 합니다.
- 검증에 실패한 파일은 설치기에 넘기지 않습니다. Apple 공증이나 macOS 권한 승인을 대신하지 않습니다.
